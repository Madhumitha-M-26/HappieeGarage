# Happy Garage

An online shopping website for Hot Wheels collectors.

## Tech
- Client: HTML, CSS, JavaScript, jQuery
- Server: Firebase (Auth + Firestore)

## Features
- Sign up, sign in, reset password
- Admin: category and car CRUD, pagination, activate/deactivate, delete with confirmation
- Admin: customer credit limit management
- Admin: customer, inventory and sales reports
- Customer: search, category filter, cart, cash/credit checkout, bill, order history

## Run
Open `index.html` with VS Code Live Server.
